# 8편. NEIS (급식, 학사일정, 시간표)

> 나이스(NEIS)에 있는 **급식, 학사일정, 시간표**를 DataGSM이 미리 가져와 두고, 교내 서비스가 쉽게 쓸 수 있게 제공하는 기능입니다.

## 왜 필요합니까?

급식, 학사일정, 시간표는 교내 서비스에서 가장 많이 쓰는 정보입니다. "오늘 급식 뭐야?" 봇이나 시간표 위젯을 만드는 학생이 정말 많습니다.

이 정보는 원래 교육청의 **나이스 교육정보 개방 포털**에서 제공합니다. 그런데 서비스마다 나이스를 직접 쓰면 불편한 점이 많습니다.

- 서비스마다 나이스 API 키를 따로 발급받고, 학교 코드와 교육청 코드를 찾아야 합니다.
- 나이스가 돌려주는 데이터 형식이 복잡해서 정리하는 코드를 매번 새로 짜야 합니다.
- 메뉴 이름 옆에 알레르기 번호가 붙어 있는 것처럼, 바로 쓰기 어려운 형태로 옵니다.
- 나이스가 느리거나 잠시 멈추면 내 서비스도 같이 멈춥니다.

DataGSM은 나이스 데이터를 **미리 가져와서 깔끔하게 정리해 둡니다.** 다른 서비스는 DataGSM에 API 키 하나로 요청하기만 하면 됩니다.

## 누가 사용합니까?

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 외부 개발자 | OpenAPI | 급식, 학사일정, 시간표 조회 (`neis:read` 권한) |

NEIS는 이 시리즈에서 유일하게 **관리 화면이 없는** 기능입니다. 관리자가 직접 입력하는 데이터가 아니라 나이스에서 자동으로 가져오는 데이터라서, 외부 개발자가 API로만 씁니다.

## 기능 살펴보기

### 급식 조회

날짜별 급식 정보를 줍니다. 아침, 점심, 저녁이 따로 나옵니다.

| 정보 | 예시 |
|---|---|
| 급식 종류 | 아침, 점심, 저녁 |
| 메뉴 목록 | 쌀밥, 김치찌개, 돈까스, 배추김치 |
| 알레르기 정보 | 메뉴에 들어 있는 알레르기 유발 식품 번호 |
| 칼로리 | 650.8 Kcal |
| 원산지 | 쌀: 국내산, 돼지고기: 국내산 |
| 영양 정보 | 단백질, 지방, 탄수화물 |
| 급식 인원 | 450 |

### 학사일정 조회

시험, 방학, 공휴일 같은 학교 일정을 줍니다.

| 정보 | 예시 |
|---|---|
| 날짜 | 2025-12-15 |
| 행사명 | 기말고사 |
| 행사 내용 | 2025학년도 2학기 기말고사 |
| 수업 공제일 | 공휴일, 휴업일 등 |
| 해당 학년 | 1, 2, 3학년 |

### 시간표 조회

학년과 반을 정해서 그 반의 시간표를 줍니다.

| 정보 | 예시 |
|---|---|
| 학년, 반 | 2학년 3반 |
| 날짜, 학기 | 2025-12-15, 2학기 |
| 교시 | 1교시 |
| 과목 | 수학 |

시간표는 학년과 반이 꼭 필요하고, 날짜나 기간도 꼭 정해야 합니다. 한 번에 최대 365일까지 조회할 수 있습니다.

### 날짜로 찾기

세 가지 모두 날짜로 찾는 방법이 같습니다.

- **특정 날짜**: 그날의 정보만 받습니다.
- **기간**: 시작 날짜와 끝 날짜 사이의 정보를 받습니다.
- **아무것도 안 정하면**: 오늘 정보를 받습니다. (급식, 학사일정만 해당됩니다)

### 자동 동기화

DataGSM은 **매일 새벽 2시쯤** 나이스에서 데이터를 새로 가져옵니다. 급식, 학사일정, 시간표 순서로 10분 간격을 두고 가져옵니다.

이때 **이번 학년도 전체**(3월 1일부터 다음 해 2월 말까지)를 한 번에 가져옵니다. 그래서 학교가 나이스에 일정이나 급식을 고치면, 다음 날부터 DataGSM에도 반영됩니다.

외부 서비스가 요청할 때마다 나이스에 물어보는 게 아니라, DataGSM이 미리 가져와 둔 데이터를 바로 돌려줍니다. 그래서 응답이 빠르고, 나이스가 잠시 멈춰도 이미 가져온 데이터는 계속 제공할 수 있습니다.

## 다른 도메인과의 관계

- **API 키 (3편)**: NEIS 데이터를 받으려면 `neis:read` 권한이 있는 API 키가 필요합니다. 이 권한은 모든 사용자가 받을 수 있습니다.
- **이벤트 (9편)**: NEIS 데이터는 이벤트를 보내지 않습니다. 이벤트는 학생, 동아리, 프로젝트만 지원합니다.

## 기억할 용어

| 용어 | 뜻 |
|---|---|
| NEIS (나이스) | 교육청이 운영하는 교육 행정 정보 시스템. 급식, 학사일정, 시간표 데이터를 공개합니다. |
| 동기화 | 나이스의 데이터를 DataGSM으로 가져와 최신 상태로 맞추는 것 |
| 학년도 | 3월 1일에 시작해서 다음 해 2월 말에 끝나는 학교의 1년 |
| 수업 공제일 | 공휴일, 휴업일처럼 수업을 하지 않는 날 |

## 한 번 더 정리

- DataGSM은 나이스의 급식, 학사일정, 시간표를 정리해서 API로 제공합니다.
- 관리 화면은 없고, 외부 개발자가 `neis:read` 권한의 API 키로 씁니다.
- 매일 새벽 2시쯤 이번 학년도 전체 데이터를 나이스에서 새로 가져옵니다.
- 시간표는 학년, 반, 날짜를 꼭 정해야 하고 최대 365일까지 조회할 수 있습니다.
