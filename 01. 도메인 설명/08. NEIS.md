# 8편. NEIS (급식, 학사일정, 시간표)

나이스(NEIS)의 급식, 학사일정, 시간표 데이터를 DataGSM이 미리 가져와 정리해 두고 API로 제공합니다.

## 필요한 이유

급식, 학사일정, 시간표는 교육청의 나이스 교육정보 개방 포털에서 제공합니다. 서비스마다 나이스를 직접 쓰면 다음 문제가 있습니다.

- 서비스마다 나이스 API 키를 발급받고 학교 코드와 교육청 코드를 찾아야 합니다.
- 나이스 응답 형식이 복잡해서 정리하는 코드를 따로 짜야 합니다. 예를 들어 메뉴 이름 옆에 알레르기 번호가 붙어서 옵니다.
- 나이스가 느리거나 멈추면 내 서비스도 영향을 받습니다.

DataGSM은 나이스 데이터를 미리 가져와 정리해 두고, 다른 서비스는 DataGSM API 키로 조회합니다.

## 사용자

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 외부 개발자 | OpenAPI | 급식, 학사일정, 시간표 조회 (`neis:read` 권한) |

나이스에서 자동으로 가져오는 데이터라서 관리 화면은 없습니다.

## 기능

### 급식 조회

날짜별 급식 정보를 아침, 점심, 저녁으로 나눠 제공합니다.

| 정보 | 예시 |
|---|---|
| 급식 종류 | 아침, 점심, 저녁 |
| 메뉴 목록 | 쌀밥, 김치찌개, 돈까스, 배추김치 |
| 알레르기 정보 | 메뉴에 들어 있는 알레르기 유발 식품 번호 |
| 칼로리 | 650.8 Kcal |
| 원산지 | 쌀: 국내산, 돼지고기: 국내산 |
| 영양 정보 | 단백질, 지방, 탄수화물 |
| 급식 인원 | 450 |

### 학사일정 조회

시험, 방학, 공휴일 같은 학교 일정을 제공합니다.

| 정보 | 예시 |
|---|---|
| 날짜 | 2025-12-15 |
| 행사명 | 기말고사 |
| 행사 내용 | 2025학년도 2학기 기말고사 |
| 수업 공제일 | 공휴일, 휴업일 등 |
| 해당 학년 | 1, 2, 3학년 |

### 시간표 조회

학년과 반을 지정해 그 반의 시간표를 제공합니다.

| 정보 | 예시 |
|---|---|
| 학년, 반 | 2학년 3반 |
| 날짜, 학기 | 2025-12-15, 2학기 |
| 교시 | 1교시 |
| 과목 | 수학 |

시간표는 학년, 반, 날짜(또는 기간)를 반드시 지정해야 하고, 한 번에 최대 365일까지 조회할 수 있습니다.

### 날짜 지정

세 API 모두 날짜를 같은 방식으로 지정합니다.

- 특정 날짜: 그날의 정보를 받습니다.
- 기간: 시작 날짜와 끝 날짜 사이의 정보를 받습니다.
- 지정하지 않음: 오늘 정보를 받습니다. (급식, 학사일정만 해당)

### 자동 동기화

DataGSM은 매일 새벽 2시부터 나이스 데이터를 다시 가져옵니다. 급식(2시), 학사일정(2시 10분), 시간표(2시 20분) 순서입니다.

한 번에 이번 학년도 전체(3월 1일부터 다음 해 2월 말까지)를 가져오므로, 학교가 나이스 데이터를 고치면 다음 날 DataGSM에도 반영됩니다.

조회 요청이 오면 나이스를 호출하지 않고 미리 가져온 데이터로 응답합니다. 그래서 나이스가 잠시 멈춰도 이미 가져온 데이터는 계속 제공됩니다.

## 다른 도메인과의 관계

- API 키 (3편): NEIS 데이터를 조회하려면 `neis:read` 권한이 있는 API 키가 필요합니다. 이 권한은 모든 사용자가 받을 수 있습니다.
- 이벤트 (9편): NEIS 데이터는 이벤트를 보내지 않습니다.

## 용어

| 용어 | 뜻 |
|---|---|
| NEIS (나이스) | 교육청이 운영하는 교육 행정 정보 시스템 |
| 동기화 | 나이스 데이터를 DataGSM으로 가져와 최신 상태로 맞추는 것 |
| 학년도 | 3월 1일에 시작해서 다음 해 2월 말에 끝나는 학교의 1년 |
| 수업 공제일 | 공휴일, 휴업일처럼 수업을 하지 않는 날 |
