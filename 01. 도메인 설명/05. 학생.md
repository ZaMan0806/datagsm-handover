# 5편. 학생 (Student)

학교 전체 학생의 명부입니다. 교내 서비스들이 같은 학생 정보를 쓰도록 DataGSM에서 관리합니다.

## 필요한 이유

교내 서비스는 대부분 학년, 반, 학과, 기숙사 호실 같은 학생 정보를 씁니다. 서비스마다 학생 정보를 따로 모으면 다음 문제가 생깁니다.

- 학생은 서비스마다 같은 정보를 다시 입력해야 합니다.
- 서비스마다 정보가 달라집니다. 작년 반 정보를 그대로 쓰는 서비스도 생깁니다.
- 새 학기마다 서비스마다 학생 정보를 다시 정리해야 합니다.

DataGSM이 학생 정보를 관리하고, 다른 서비스는 이를 조회해서 씁니다. DataGSM이 다루는 학생 정보는 학년, 반, 기숙사 호실처럼 학교에서 공개적으로 관리하는 정보입니다.

## 사용자

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 관리자 | 관리자 페이지의 학생 관리 화면 | 학생 등록, 수정, 엑셀 업로드·다운로드, 졸업·자퇴 처리, 정보 수정 요청 |
| 학생 | 개발자 콘솔의 내 정보 화면 | 내 정보 확인, 진로와 GitHub 아이디 수정 |
| 학생 | 로그인 페이지 | 정보 수정 요청 받은 항목 입력 |
| 외부 개발자 | OpenAPI | 학생 정보 조회 (`student:read` 권한) |

## 학생 정보 항목

| 항목 | 설명 |
|---|---|
| 이름, 이메일, 성별 | 이메일은 학교 이메일입니다. |
| 학번 | 학년, 반, 번호 |
| 학과 | SW개발과, 스마트IoT과, 인공지능과 |
| 기숙사 호실 | 기숙사 방 번호 |
| 전공 동아리, 자율 동아리 | 소속 동아리 |
| 학생 구분 | 일반학생, 학생회, 기숙사자치위원회, 졸업생, 자퇴생 |
| 진로 | 프론트엔드, 백엔드, AI, 안드로이드 등 희망 분야 |
| GitHub 아이디 | 학생의 GitHub 계정 |

학생 정보는 계정과 별개입니다. 관리자가 학생 정보를 먼저 등록해 두면, 학생이 같은 이메일로 가입할 때 계정과 연결됩니다.

## 기능

### 학생 조회와 검색

관리자 페이지의 학생 관리 화면에서 학생 목록을 봅니다. 다음 조건으로 거를 수 있습니다.

- 학년, 반
- 성별
- 학생 구분 (학생회, 기숙사자치위원회 등)
- 이름
- 졸업생, 자퇴생 포함 여부

### 학생 등록과 수정

관리자는 학생을 한 명씩 추가하거나 수정합니다. 학생 구분만 바꾸면 상태만 변경되고, 다른 항목을 바꾸면 해당 정보가 수정됩니다.

### 엑셀 다운로드와 업로드

- 다운로드: 등록된 학생 정보를 엑셀 파일로 받습니다.
- 업로드: 수정한 엑셀 파일을 올려 학생 정보를 한 번에 바꿉니다.

엑셀 업로드는 이미 등록된 학생의 정보를 한꺼번에 수정하는 기능입니다. 엑셀의 학번으로 학생을 찾기 때문에 엑셀의 학번 목록과 DataGSM의 학번 목록이 정확히 같아야 합니다. 학번이 빠지거나 중복되거나, 없는 동아리 이름이 있으면 업로드가 거부됩니다. 보통은 다운로드한 파일을 수정해서 다시 올립니다.

### 졸업과 자퇴 처리

- 특정 학생 졸업 처리: 한 명을 졸업생으로 바꿉니다.
- 3학년 전체 졸업 처리: 3학년 전체를 졸업생으로 바꿉니다.
- 특정 학생 자퇴 처리: 한 명을 자퇴생으로 바꿉니다.

졸업생이나 자퇴생이 되면 학번, 학과, 기숙사 호실, 소속 동아리가 비워집니다. 한 명씩 처리하면 진로와 동아리 부장 자리도 함께 비워집니다. 학생 정보 자체는 삭제되지 않으므로 졸업생도 DataGSM 계정을 계속 쓸 수 있습니다.

되돌릴 수 없는 작업이라 실행 전에 확인 창이 나옵니다.

### 정보 수정 요청

2편의 정보 수정 요구를 보내는 기능입니다. 새 학기에 바뀐 학번, 기숙사 호실, 동아리를 학생이 직접 입력하게 할 때 씁니다.

1. 관리자가 학생 관리 화면에서 대상 학생을 고릅니다.
2. 다시 입력받을 항목을 고릅니다. 학번, 기숙사 호실, 전공 동아리, 자율 동아리 중에서 고를 수 있습니다.
3. 요청을 보내면 고른 항목이 바로 비워집니다.
4. 학생은 다음 로그인 때 그 항목을 입력해야 로그인이 끝납니다.

되돌릴 수 없는 작업이라 실행 전에 확인 창이 나옵니다.

### 학생이 직접 수정할 수 있는 정보

학생은 개발자 콘솔의 내 정보 화면에서 두 가지를 수정할 수 있습니다.

- 진로: 목록에서 고르거나 직접 입력합니다. 목록에는 프론트엔드, 백엔드, AI, 안드로이드, iOS, 플러터, IoT, 공기업·금융권, 클라우드·DevOps, PM·PO, 부사관, IT 엔지니어, 보안, 로보틱스, 게임개발이 있습니다.
- GitHub 아이디: 등록하면 GitHub 프로필 링크로 표시됩니다.

학번, 동아리 등 나머지 항목은 관리자가 수정하거나, 정보 수정 요청을 받았을 때만 학생이 입력할 수 있습니다.

### OpenAPI 제공

외부 서비스는 `student:read` 권한이 있는 API 키로 학생 정보를 조회합니다.

조회 결과에는 DataGSM에 가입한 학생만 포함됩니다. 가입할 때 개인정보 처리약관에 동의한 학생의 데이터만 내보내기 때문입니다.

관리자용 API 키(`student:write`)로는 OpenAPI에서 학생 정보를 등록하거나 수정할 수 있습니다.

## 다른 도메인과의 관계

- 계정 (1편): 학생 정보와 계정은 이메일로 연결됩니다.
- 로그인 (2편): 정보 수정 요청을 받은 학생은 로그인할 때 정보를 입력합니다.
- 동아리 (6편): 학생은 전공 동아리와 자율 동아리에 하나씩 소속될 수 있습니다. 동아리 부장도 학생입니다.
- 프로젝트 (7편): 프로젝트 참여자는 재학생 중에서 고릅니다.
- 이벤트 (9편): 학생 정보가 바뀌면(수정, 졸업, 자퇴, 정보 수정 요청 등) `student.updated` 이벤트가 전송됩니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 학생 명부 | DataGSM에 등록된 학생 정보 전체 |
| 학생 구분 | 일반학생, 학생회, 기숙사자치위원회, 졸업생, 자퇴생 |
| 학과 (major) | SW개발과, 스마트IoT과, 인공지능과 |
| 진로 (specialty) | 학생이 직접 정하는 희망 분야. 학과와 다릅니다. |
| 정보 수정 요청 | 관리자가 고른 항목을 비우고, 학생이 로그인할 때 다시 입력하게 하는 기능 |
