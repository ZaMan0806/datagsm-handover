# 6편. 동아리 (Club)

> 우리 학교 동아리의 **목록과 구성원 정보**예요. 어떤 동아리가 있는지, 누가 부장이고 누가 부원인지 한곳에서 관리해요.

## 왜 필요한가요?

동아리 정보는 생각보다 여러 곳에서 쓰여요.

- 동아리 소개 페이지나 동아리 신청 서비스
- "우리 동아리가 만든 프로젝트"를 모아 보여 주는 곳
- 학생 정보에 "어느 동아리 소속인지" 보여 주는 곳

그런데 동아리는 매년 새로 생기거나 없어지고, 부장과 부원도 바뀌어요. 서비스마다 동아리 목록을 따로 관리하면 금방 서로 달라져요. 그래서 DataGSM이 동아리 정보를 한곳에서 관리하고, 다른 서비스는 그 정보를 가져다 써요.

## 누가 쓰나요?

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 관리자 | 관리자 페이지의 동아리 관리 화면 | 동아리 등록, 수정, 삭제, 엑셀 업로드·다운로드 |
| 누구나 | 프로젝트 사이트 등 | 동아리 목록 보기 (로그인 없이) |
| 외부 개발자 | OpenAPI | 동아리 정보 조회 (`club:read` 권한) |

## 동아리 정보에는 무엇이 있나요?

| 항목 | 설명 |
|---|---|
| 동아리 이름 | 동아리 이름. 다른 동아리와 겹칠 수 없어요. |
| 동아리 종류 | 전공 동아리, 자율 동아리(창체 동아리) |
| 창설 학년도 | 동아리가 만들어진 해 |
| 운영 상태 | 운영 중, 폐지 |
| 폐지 학년도 | 폐지된 경우 폐지된 해 |
| 부장 | 동아리 부장 학생 |
| 부원 | 이 동아리에 소속된 학생들 |

### 동아리 종류

우리 학교 동아리는 두 종류가 있어요.

- **전공 동아리**: 전공(개발) 분야 동아리예요.
- **자율 동아리**: 창의적 체험활동 동아리예요. 서버에서는 창체 동아리, 화면에서는 자율 동아리라고 불러요.

학생 한 명은 **전공 동아리 하나와 자율 동아리 하나**에 소속될 수 있어요. 그래서 학생 정보에도 전공 동아리와 자율 동아리 칸이 따로 있어요. ([5편](./05.%20학생.md) 참고)

## 기능 살펴보기

### 동아리 조회

관리자 페이지에서 동아리 목록을 보고, 동아리 이름으로 검색하거나 동아리 종류와 운영 상태로 걸러 볼 수 있어요. 동아리를 누르면 부장과 부원 목록도 보여요.

### 동아리 등록과 수정

관리자는 동아리를 만들거나 정보를 고칠 수 있어요. 수정할 때는 부장과 부원도 함께 정해요. 부원은 학년별로 학생을 골라서 지정해요.

실수를 막기 위해 몇 가지 규칙이 있어요.

- 같은 이름의 동아리를 만들 수 없어요.
- **운영 중**인 동아리에는 부장이나 부원이 최소 한 명 있어야 해요.
- **폐지**된 동아리에는 부장이나 부원을 지정할 수 없어요.

### 동아리 폐지와 삭제

동아리가 없어지는 방법은 두 가지예요.

- **폐지**: 운영 상태를 "폐지"로 바꾸고 폐지 학년도를 적어요. 동아리 기록은 남아서 "예전에 이런 동아리가 있었다"는 걸 알 수 있어요.
- **삭제**: 동아리 정보 자체를 지워요.

삭제하면 그 동아리에 소속된 학생들의 동아리 칸이 **비워져요.** 보통은 기록을 남기기 위해 삭제보다 폐지를 써요.

### 엑셀 다운로드와 업로드

동아리도 엑셀로 한 번에 관리할 수 있어요. 엑셀에는 동아리명, 동아리 종류, 부장, 창설 학년도, 운영 상태, 폐지 학년도가 들어가요.

- **다운로드**: 지금 동아리 현황을 엑셀 파일로 받아요.
- **업로드**: 엑셀 내용대로 동아리 정보를 맞춰요.

엑셀 업로드는 **엑셀 파일을 기준으로 전체 동아리 목록을 맞추는** 방식이라 조심해서 써야 해요.

| 엑셀 내용 | 결과 |
|---|---|
| 이미 있는 동아리 | 엑셀 내용으로 정보가 바뀌어요. |
| 새로운 동아리 | 새로 만들어져요. |
| 폐지로 적은 동아리 | 부장이 비워지고, 소속 학생들의 동아리 칸도 비워져요. |
| **엑셀에 없는 동아리** | **삭제돼요.** 소속 학생들의 동아리 칸도 비워져요. |

그래서 학생 엑셀과 마찬가지로, **다운로드한 파일을 고쳐서 다시 올리는** 방식으로 쓰는 게 안전해요.

### 공개 조회

동아리 목록은 **로그인하지 않아도** 볼 수 있어요. 예를 들어 프로젝트 사이트에서 "이 동아리의 프로젝트"로 걸러 볼 때 이 목록을 써요.

누구나 쓸 수 있는 만큼, 공개 조회는 **1분에 60번**까지만 요청할 수 있어요.

### OpenAPI로 동아리 정보 제공

외부 서비스는 `club:read` 권한이 있는 API 키로 동아리 정보를 조회할 수 있어요. 관리자 권한이 있는 API 키(`club:write`)로는 동아리를 등록하거나 고칠 수도 있어요.

## 다른 도메인과의 관계

- **학생 (5편)**: 학생은 전공 동아리와 자율 동아리에 하나씩 소속돼요. 부장도 학생이에요.
- **로그인 (2편)**: 정보 수정 요청으로 학생이 로그인할 때 소속 동아리를 다시 고를 수 있어요.
- **프로젝트 (7편)**: 프로젝트는 동아리에 속할 수 있어요. 동아리 프로젝트를 모아 볼 수 있어요.
- **이벤트 (9편)**: 동아리가 만들어지거나, 바뀌거나, 삭제되면 `club.updated` 이벤트로 외부 서비스에 알려요.

## 기억할 용어

| 용어 | 뜻 |
|---|---|
| 전공 동아리 | 전공(개발) 분야 동아리 |
| 자율 동아리 (창체 동아리) | 창의적 체험활동 동아리 |
| 폐지 | 동아리 기록은 남기고 운영만 끝내는 것 |
| 공개 조회 | 로그인 없이 누구나 볼 수 있는 조회 |

## 한 번 더 정리

- 동아리는 전공 동아리와 자율 동아리 두 종류이고, 학생은 각각 하나씩 소속될 수 있어요.
- 운영 중인 동아리에는 부장이나 부원이 최소 한 명 있어야 해요.
- 동아리를 없앨 때는 기록이 남는 폐지를 주로 써요.
- 엑셀 업로드는 엑셀에 없는 동아리를 삭제하니 조심해야 해요.
- 동아리 목록은 로그인 없이도 볼 수 있어요.
