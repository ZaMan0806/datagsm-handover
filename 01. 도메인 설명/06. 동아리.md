# 6편. 동아리 (Club)

> 학교 동아리 목록과 부장, 부원 정보를 관리합니다.

## 필요한 이유

동아리 정보는 동아리 소개·신청 서비스, 동아리 프로젝트 목록, 학생의 소속 동아리 표시 등에 쓰입니다. 동아리는 매년 새로 생기거나 없어지고 부장과 부원도 바뀌기 때문에, 서비스마다 따로 관리하면 내용이 서로 달라집니다. 그래서 DataGSM에서 동아리 정보를 관리하고 다른 서비스는 이를 조회해서 씁니다.

## 사용자

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 관리자 | 관리자 페이지의 동아리 관리 화면 | 동아리 등록, 수정, 삭제, 엑셀 업로드·다운로드 |
| 누구나 | 프로젝트 사이트 등 | 동아리 목록 조회 (로그인 없이) |
| 외부 개발자 | OpenAPI | 동아리 정보 조회 (`club:read` 권한) |

## 동아리 정보 항목

| 항목 | 설명 |
|---|---|
| 동아리 이름 | 다른 동아리와 중복될 수 없습니다. |
| 동아리 종류 | 전공 동아리, 자율 동아리(창체 동아리) |
| 창설 학년도 | 동아리가 만들어진 해 |
| 운영 상태 | 운영 중, 폐지 |
| 폐지 학년도 | 폐지된 해 |
| 부장 | 동아리 부장 학생 |
| 부원 | 동아리에 소속된 학생 |

### 동아리 종류

- 전공 동아리: 전공(개발) 분야 동아리입니다.
- 자율 동아리: 창의적 체험활동 동아리입니다. 서버에서는 창체 동아리, 화면에서는 자율 동아리라고 표시합니다.

학생은 전공 동아리와 자율 동아리에 하나씩 소속될 수 있고, 학생 정보에도 두 항목이 따로 있습니다. ([5편](./05.%20학생.md) 참고)

## 기능

### 동아리 조회

관리자 페이지에서 동아리 목록을 보고, 이름으로 검색하거나 종류와 운영 상태로 거를 수 있습니다. 동아리를 누르면 부장과 부원 목록이 나옵니다.

### 동아리 등록과 수정

관리자는 동아리를 만들거나 수정합니다. 수정할 때 부장과 부원도 지정하며, 부원은 학년별로 학생을 골라 지정합니다.

규칙은 다음과 같습니다.

- 같은 이름의 동아리는 만들 수 없습니다.
- 운영 중인 동아리에는 부장이나 부원이 한 명 이상 있어야 합니다.
- 폐지된 동아리에는 부장이나 부원을 지정할 수 없습니다.

### 동아리 폐지와 삭제

- 폐지: 운영 상태를 폐지로 바꾸고 폐지 학년도를 적습니다. 동아리 기록은 남습니다.
- 삭제: 동아리 정보를 지웁니다. 소속 학생들의 동아리 항목이 비워집니다.

기록을 남기려면 삭제 대신 폐지를 씁니다.

### 엑셀 다운로드와 업로드

엑셀에는 동아리명, 동아리 종류, 부장, 창설 학년도, 운영 상태, 폐지 학년도가 들어갑니다.

- 다운로드: 현재 동아리 현황을 엑셀 파일로 받습니다.
- 업로드: 엑셀 내용에 맞춰 전체 동아리 목록을 바꿉니다.

업로드 결과는 다음과 같습니다.

| 엑셀 내용 | 결과 |
|---|---|
| 이미 있는 동아리 | 엑셀 내용으로 수정됩니다. |
| 새로운 동아리 | 새로 만들어집니다. |
| 폐지로 적은 동아리 | 부장과 소속 학생들의 동아리 항목이 비워집니다. |
| 엑셀에 없는 동아리 | **삭제되고, 소속 학생들의 동아리 항목도 비워집니다.** |

엑셀에 없는 동아리는 삭제되므로, 다운로드한 파일을 수정해서 올려야 합니다.

### 공개 조회

동아리 목록은 로그인 없이 조회할 수 있습니다. 프로젝트 사이트의 동아리 필터가 이 목록을 씁니다. 공개 조회는 1분에 60번까지 요청할 수 있습니다.

### OpenAPI 제공

외부 서비스는 `club:read` 권한이 있는 API 키로 동아리 정보를 조회합니다. 관리자용 API 키(`club:write`)로는 동아리를 등록하거나 수정할 수 있습니다.

## 다른 도메인과의 관계

- 학생 (5편): 학생은 전공 동아리와 자율 동아리에 하나씩 소속됩니다. 부장도 학생입니다.
- 로그인 (2편): 정보 수정 요청을 받은 학생은 로그인할 때 소속 동아리를 다시 고릅니다.
- 프로젝트 (7편): 프로젝트는 동아리에 속할 수 있습니다.
- 이벤트 (9편): 동아리가 만들어지거나, 수정되거나, 삭제되면 `club.updated` 이벤트가 전송됩니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 전공 동아리 | 전공(개발) 분야 동아리 |
| 자율 동아리 (창체 동아리) | 창의적 체험활동 동아리 |
| 폐지 | 동아리 기록은 남기고 운영만 끝내는 것 |
| 공개 조회 | 로그인 없이 누구나 할 수 있는 조회 |
