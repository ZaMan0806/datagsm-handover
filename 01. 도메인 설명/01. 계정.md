# 1편. 계정 (Account)

DataGSM 회원 정보입니다. 학교 이메일로만 가입할 수 있고, 계정마다 권한 등급이 있습니다.

## 필요한 이유

DataGSM은 학생 정보 같은 학교 데이터를 다룹니다. 그래서 `@gsm.hs.kr` 이메일을 가진 사람만 가입할 수 있게 하고, 계정마다 권한 등급을 두어 할 수 있는 일을 나눕니다.

API 키, OAuth 클라이언트, 애플리케이션, 이벤트는 모두 만든 계정에 속합니다.

## 사용자

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 학생, 선생님 | 로그인 페이지 | 회원가입, 비밀번호 재설정 |
| 로그인한 모든 사용자 | 개발자 콘솔의 내 정보 화면 | 내 정보 확인, 회원 탈퇴 |
| 관리자 | 관리자 페이지의 계정 관리, 선생님 승인 화면 | 계정 검색, 권한 변경, 선생님 가입 승인 |

### 회원가입

학생 가입과 선생님 가입이 있고, 둘 다 이메일 인증을 거칩니다.

1. 학교 이메일을 입력하면 인증 코드가 메일로 옵니다. 코드는 5분 동안 유효합니다.
2. 받은 코드를 입력합니다.
3. 비밀번호를 정하면 가입이 끝납니다.

`@gsm.hs.kr`이 아닌 이메일이나 이미 가입된 이메일로는 가입할 수 없습니다.

학생 계정은 가입 즉시 쓸 수 있습니다. 가입할 때 같은 이메일을 가진 학생 정보를 학생 명부에서 찾아 계정과 연결합니다. 그래서 학생은 학번이나 이름을 따로 입력하지 않습니다.

선생님은 이름과 소속 부서를 함께 입력합니다. 소속 부서는 마이스터부, 사감선생님, 학년부, 교무부, 전문교육부, 취업진로부, 행정실 중에서 고릅니다. 선생님 계정은 승인 대기 상태로 만들어지고, 관리자가 승인해야 로그인할 수 있습니다.

### 선생님 가입 승인

학생이 선생님으로 가입하는 것을 막기 위해 선생님 계정은 관리자 승인을 받아야 합니다.

관리자 페이지의 선생님 승인 화면에 승인 대기 중인 선생님 목록이 나옵니다. 이름, 이메일, 소속 부서, 설명, 신청일이 함께 보입니다.

- 허락: 계정이 활성 상태가 되어 로그인할 수 있습니다.
- 거절: 계정과 선생님 정보가 삭제됩니다. 되돌릴 수 없습니다.

### 비밀번호 재설정

<img src="https://res.cloudinary.com/dthsnnmej/image/upload/v1793707811/themoment-blog/mtzpetrbkbprfoyflrfj.png" width="600" alt="이미지" />

이메일 인증 코드로 비밀번호를 다시 정합니다.

1. 이메일을 입력하면 재설정 코드가 메일로 옵니다. 코드는 5분 동안 유효합니다.
2. 코드를 입력합니다.
3. 새 비밀번호를 정합니다.

가입되지 않은 이메일을 입력해도 없는 이메일이라고 알려 주지 않습니다. 어떤 이메일이 가입되어 있는지 다른 사람이 알아낼 수 없게 하기 위해서입니다.

### 시도 횟수 제한

인증 코드는 8자리 숫자입니다. 아무 숫자나 계속 넣어 맞히는 공격을 막기 위해, 같은 이메일로 짧은 시간에 너무 많이 시도하면 잠시 막습니다.

| 동작 | 허용 횟수 |
|---|---|
| 회원가입 인증 메일 보내기 | 10분에 5번 |
| 회원가입 인증 코드 확인 | 5분에 10번 |
| 비밀번호 재설정 메일 보내기 | 10분에 3번 |
| 비밀번호 재설정 코드 확인 | 10분에 5번 |
| 비밀번호 변경 | 60분에 3번 |
| 로그인 | 10분에 10번 |

### 권한 등급

계정마다 세 등급 중 하나가 붙습니다. 관리자 페이지에서는 루트, 어드민, 유저로 표시됩니다.

| 등급 | 대상 | 할 수 있는 일 |
|---|---|---|
| 유저 (USER) | 가입한 모든 사람의 기본 등급 | 내 정보 관리, 읽기 권한 API 키 발급, OAuth 클라이언트·애플리케이션·이벤트 등록 |
| 어드민 (ADMIN) | 운영진 | 유저 기능 전부 + 관리자 페이지 (학생, 동아리, 프로젝트, 계정, API 키 관리) |
| 루트 (ROOT) | 최고 관리자 | 어드민과 같은 기능. 다른 사람이 권한을 바꿀 수 없음 |

### 계정 관리와 권한 변경

관리자 페이지의 계정 관리 화면에서 전체 계정을 이메일, 권한, 상태로 검색합니다. 계정을 누르면 연결된 학생 정보나 선생님 정보도 보입니다.

관리자는 여기서 다른 계정의 권한을 바꿀 수 있습니다. 다음은 막혀 있습니다.

- 본인 계정의 권한 변경
- 루트 계정의 권한 변경
- 루트 권한 부여

### 내 정보와 회원 탈퇴

<img src="https://res.cloudinary.com/dthsnnmej/image/upload/v1793707862/themoment-blog/vbsayy0v2jf99fjh98st.png" width="600" alt="이미지" />

개발자 콘솔의 내 정보 화면에서 계정 정보와 연결된 학생 정보(학번, 기숙사 호실, 동아리 등)를 봅니다. 학생은 여기서 진로와 GitHub 아이디를 고칠 수 있습니다.

회원 탈퇴는 비밀번호를 다시 입력해야 진행됩니다. 탈퇴하면 그 계정으로 만든 다음 항목이 모두 삭제됩니다.

- API 키
- OAuth 클라이언트와 애플리케이션
- 이벤트
- 외부 서비스에 한 동의 기록
- 로그인 세션

학생 명부의 학생 정보는 계정과 별개라서 탈퇴해도 남습니다.

## 다른 도메인과의 관계

- 학생, 선생님: 계정은 로그인하는 주체이고, 학생 정보와 선생님 정보는 그 사람의 신상 정보입니다. 둘은 이메일로 연결됩니다.
- 로그인 (2편): 이 계정으로 DataGSM 로그인을 합니다. 승인 대기 중인 선생님은 로그인할 수 없습니다.
- API 키 (3편): 권한 등급에 따라 발급받을 수 있는 권한 범위가 다릅니다.
- OpenAPI: OpenAPI로 제공하는 학생 데이터에는 DataGSM에 가입한 학생만 포함됩니다. 가입할 때 개인정보 처리약관에 동의한 학생의 데이터만 내보내기 때문입니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 승인 대기 (PENDING) | 가입은 했지만 아직 쓸 수 없는 상태. 선생님 계정의 처음 상태입니다. |
| 활성 (ACTIVE) | 정상적으로 쓸 수 있는 상태 |
| 권한 등급 (Role) | 루트, 어드민, 유저. 계정이 할 수 있는 일의 범위 |
| 계정 연결 | 계정을 학생 정보나 선생님 정보와 이어 주는 것 |
