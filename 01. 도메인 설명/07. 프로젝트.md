# 7편. 프로젝트 (Project)

<img src="https://res.cloudinary.com/dthsnnmej/image/upload/v1793713724/themoment-blog/mio0aa8unytcvdskbfkv.png" width="600" alt="이미지" />

학생들이 만든 프로젝트를 등록하고 공개하는 기능입니다. 만든 사람, 기간, 기술 스택, 배포 주소 등을 기록합니다.

## 필요한 이유

학생들이 만든 토이 프로젝트, 팀 프로젝트, 동아리 프로젝트, 아이디어페스티벌 결과물은 따로 모아 두는 곳이 없어서 다음 문제가 있습니다.

- 졸업한 선배가 만든 서비스를 찾기 어렵습니다.
- 교내에서 운영 중인 서비스 목록을 알기 어렵습니다.
- 학생이 자기 프로젝트를 정리해 둘 곳이 없습니다.

DataGSM은 프로젝트를 등록받아 기록하고, 누구나 볼 수 있게 공개합니다.

## 사용자

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 누구나 | 프로젝트 사이트 | 등록된 프로젝트 조회 (로그인 없이) |
| 학생 | 프로젝트 사이트의 내 프로젝트 화면 | 프로젝트 등록 신청, 수정 신청, 신청 결과 확인 |
| 관리자 | 관리자 페이지의 프로젝트 관리, 프로젝트 신청 화면 | 신청 수락·거절, 프로젝트 직접 등록·수정·종료·삭제 |
| 외부 개발자 | OpenAPI | 프로젝트 정보 조회 (`project:read` 권한) |

| 카테고리 | 토이 프로젝트, 팀 프로젝트, 동아리 프로젝트, 아이디어페스티벌, 미배포 (여러 개 선택 가능) |

## 기능

### 프로젝트 조회

프로젝트 사이트에서 로그인 없이 프로젝트 목록과 상세 정보를 봅니다. 다음 조건으로 거를 수 있습니다.

- 프로젝트 이름
- 동아리
- 운영 상태 (운영 중, 종료)
- 카테고리

관리자가 수락한 프로젝트만 표시됩니다.

### 프로젝트 등록 신청

학생은 프로젝트 사이트의 내 프로젝트 화면에서 등록을 신청합니다. 학생 계정으로 로그인해야 쓸 수 있습니다.

신청서에 프로젝트 정보를 입력하고 참여자를 재학생 중에서 고릅니다. 참여자 목록에는 동명이인을 구분하도록 학번, 이름, 학과가 함께 나옵니다. 신청한 학생은 자동으로 참여자에 들어갑니다.

신청한 프로젝트는 신청 대기 상태가 되고, 관리자가 수락해야 등록됩니다.

### 신청 수락과 거절

관리자 페이지의 프로젝트 신청 화면에서 신청을 확인합니다. 신청마다 신규 등록인지 기존 프로젝트 수정인지 표시됩니다.

- 수락: 신규 신청이면 프로젝트가 만들어지고, 수정 신청이면 기존 프로젝트에 반영됩니다.
- 거절: 거절 사유를 반드시 입력해야 합니다. 기존 프로젝트는 바뀌지 않습니다.

학생은 내 프로젝트 화면에서 신청 상태(신청 대기, 수락, 거절)와 거절 사유를 봅니다. 거절된 신규 신청은 수정해서 다시 신청할 수 있습니다.

### 프로젝트 수정 신청

등록된 프로젝트를 고칠 때도 신청을 거칩니다. 수정 신청은 그 프로젝트의 신청자나 참여자만 할 수 있습니다.

수정 신청도 관리자가 수락해야 반영됩니다. 프로젝트마다 수정 신청은 하나만 유지되므로, 처리되기 전에 다시 신청하면 이전 신청 내용이 새 내용으로 바뀝니다.

### 아이콘 업로드

신청서에서 이미지 파일을 올려 아이콘을 정합니다. 아이콘 업로드는 1분에 10번까지 할 수 있습니다.

### 관리자의 프로젝트 관리

관리자는 신청 없이 관리자 페이지에서 프로젝트를 직접 관리할 수 있습니다.

- 등록, 수정: 프로젝트를 바로 만들거나 수정합니다.
- 종료: 운영 상태를 종료로 바꾸고 종료 연도를 적습니다. 종료 연도는 시작 연도보다 빠를 수 없습니다.
- 운영 재개: 종료된 프로젝트를 운영 중으로 되돌립니다. 종료 연도는 지워집니다.
- 삭제: 프로젝트를 지웁니다.

종료한 프로젝트는 기록이 남고, 삭제한 프로젝트는 기록이 사라집니다.

### OpenAPI 제공

외부 서비스는 `project:read` 권한이 있는 API 키로 프로젝트 정보를 조회합니다. 관리자용 API 키(`project:write`)로는 프로젝트를 등록하거나 수정할 수 있습니다.

## 다른 도메인과의 관계

- 학생 (5편): 신청자와 참여자는 학생입니다. 참여자는 재학생 중에서 고릅니다.
- 동아리 (6편): 동아리 프로젝트는 동아리에 속합니다. 폐지된 동아리로는 새로 신청할 수 없습니다.
- 로그인 (2편): 외부 서비스는 사용자의 동의를 받아 그 사용자가 참여한 프로젝트 목록을 받을 수 있습니다.
- 이벤트 (9편): 프로젝트가 만들어지거나, 수정되거나, 삭제되면 `project.updated` 이벤트가 전송됩니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 신청 | 학생이 프로젝트 등록이나 수정을 요청하는 것 |
| 신청자 | 프로젝트를 처음 등록 신청한 학생 |
| 참여자 | 프로젝트를 함께 만든 학생 |
| 종료 | 기록은 남기고 운영만 끝난 상태로 바꾸는 것 |
